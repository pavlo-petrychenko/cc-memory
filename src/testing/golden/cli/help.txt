memory — per-workspace memory for Claude Code

Usage:
  memory workspace add <id> --match <prefix>… [--kb PATH] [--worklogs PATH] [--exclude E…]  — register a new workspace
  memory workspace rm <id> [--purge]  — remove a workspace registration
  memory workspace ls  — list registered workspaces
  memory resolve [cwd]  — which workspace + worktree a path maps to
  memory reindex [workspace] [--full]  — rebuild the search index
  memory search <query> [--workspace ID] [--cwd PATH] [-k N] [--worklog]  — search the knowledge base + worklogs
  memory notes [--workspace ID] [--cwd PATH] [--folder F] [--json]  — enumerate indexed notes
  memory commit [workspace] [-m MSG]  — MANUAL git snapshot of a KB (local; no push)
  memory toggle [on|off|status] [--session ID]  — mute/unmute cc-memory for one host session (default: $CLAUDE_CODE_SESSION_ID)
  memory doctor [--cwd PATH] [--prompt TEXT]  — self-test hooks and diagnose the install
  memory install [--dry-run] [--agents claude,pi]  — wire into Claude Code and/or pi
  memory uninstall  — wire out of Claude Code and pi
  memory -h | --help  — show this help text
  memory -V | --version  — show the installed version

Environment:
  CCMEM_INJECT_MIN_SCORE  minimum BM25 strength to auto-inject a hit (default 0.2)
  CCMEM_LINK_BOOST        RRF bonus per corroborating in-link (default 0.003)
  CCMEM_INJECT_LOG        set to 0 to disable per-prompt retrieval logging
  CCMEM_BLOCK_AFTER       nudges before the wrap-gate may block (default 2)
  CCMEM_BLOCK_DRIFT       dirty files before the wrap-gate may block (default 5)
  CCMEM_GATE_DISABLE      set to 1 to disable wrap-gate blocking entirely
  CCMEM_LOG_LEVEL         debug | info | warn | error (default warn)
